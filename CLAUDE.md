# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Build & Run Commands
- Open `index.html` directly in browser to view the webpage
- No build process needed - this is a static HTML/JS website

## Development Guidelines
- Use TailwindCSS via CDN for styling (already imported)
- Use D3.js (v7) for visualization (already imported)
- Fonts: 'Press Start 2P' for headings, 'Roboto Mono' for body text
- Maintain cyberpunk theme with neon colors (#00f0ff, #ff00ff) and dark background
- Use Russian language for UI text
- Respect existing color scheme and animations
- Maintain mindmap data structure format when adding new nodes

## Code Style
- Use 4-space indentation
- CSS selectors should be descriptive and follow existing naming conventions
- JavaScript variables use camelCase
- Comment complex D3.js code sections
